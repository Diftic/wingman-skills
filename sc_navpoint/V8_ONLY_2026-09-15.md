# V8-only OCR and calibrated direction output

V8 (`FrameAwareReader`) is the sole runtime reader. Removed the
`specialist_ocr_candidate` setting from code and defaults. V8 load failures and
scan refusals do not select another reader. The obsolete glyph bank is excluded
from the release and installer. Shared capture/diagnostic helpers remain in
`overlay_reader.py`; historical decoder code and glyph data remain in the source
checkout for offline regression tests, with no runtime selection path.

Local ring direction now requires an explicit calibrated planet/site frame.
Untyped legacy captures may still provide distance but cannot produce a dot.
Spoken/tool guidance removes old compass labels and absolute bearings; it only
publishes target-relative angles accepted by the ring. Captures no longer derive
an uncalibrated compass heading from CamDir, and the dashboard no longer renders
HDG or calculates its own legacy direction. Navigation logs report distance
without the old uncalibrated turn instruction.

Regression checks reproduced each leak before the fix. They cover untyped,
planet and site captures, reader load failure, reader caching, settings removal,
capture output, and the actual dashboard renderer executed in Node. Existing
display tests now use calibrated fixtures where they require a valid direction.
Space guidance keeps its existing explicitly matched SolarSystem path.

Installation requires a Wingman restart and a dashboard refresh. Scan saved
Wingman YAML configurations for the removed property before deploying defaults;
an orphaned saved property can fail Wingman settings validation. The live scan
on 2026-09-15 found no saved copies outside the skill's defaults.
